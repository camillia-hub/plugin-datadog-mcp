# Datadog MCP

Reads Datadog. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/datadog-mcp

Installs from the Camillia hub as `datadog-mcp-b62135`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
